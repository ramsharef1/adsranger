# MENA ad calendar 2027 · تقويم المواسم الإعلانية 2027

Key 2027 advertising dates across the Middle East and North Africa: Ramadan, Eid, national days and sale seasons, with when to start planning and a source for every date. The same data as the free seasons calendar at **https://adsranger.com/en/mena-calendar** (Arabic: https://adsranger.com/mena-calendar). The website is always the latest version.

أهم مواعيد الإعلان في الشرق الأوسط وشمال أفريقيا لعام 2027: رمضان والأعياد والأيام الوطنية ومواسم التخفيضات، مع موعد بدء التخطيط ومصدر لكل موعد. هي نفس بيانات تقويم المواسم المجاني على https://adsranger.com/mena-calendar.

## Files
- `mena-ad-calendar-2027.csv`: one row per date, in Arabic and English (UTF-8 with BOM, so it opens correctly in Excel).
- `mena-ad-calendar-2027.json`: the same rows, plus title, licence and retrieval date.

## Columns
`id` · `date_en` / `date_ar` · `event_en` / `event_ar` · `note_en` / `note_ar` · `countries_en` / `countries_ar` · `status` (`fixed` = an official fixed date; `expected` = a Hijri or announced-later date that can move by a day or more) · `start_planning_en` / `start_planning_ar` · `source_name` · `source_url`

## Please note
- Hijri dates are **expected**. Final dates depend on each country's moon sighting and official announcements. Check the source before you book media.
- Dates are updated after the official Ramadan announcements (early Feb 2027).
