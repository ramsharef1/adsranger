#### 4. Candidate `BROKEN` Items & Environment Risks Found
- **Candidate BROKEN-1 (4 failing tests on macOS / case-insensitive filesystems):**
  - **What:** `GET /app/{agency}/calendar` throws HTTP 500 `TypeError: htmlspecialchars(): Argument #1 ($string) must be of type string, array given` when locale is `en`.
  - **Where:** `resources/views/filament/pages/mena-calendar.blade.php` lines 56 & 58 (`__('Plan')`) and `resources/views/components/locked-button.blade.php` line 7.
  - **Why:** In Laravel's translator, `__('Plan')` checks for a translation group named `Plan` before falling back to JSON/key. On macOS (case-insensitive APFS), `lang/en/plan.php` matches `'Plan'` and returns the entire `lang/en/plan.php` array instead of the string `'Plan'`.
- **Environment Risk-2 (Local Mac PHP version):**
  - Rami's Mac runs Homebrew `PHP 8.5.9`, whereas the server runs `PHP 8.4`. E2 will strictly target PHP 8.4 compatibility and never use PHP 8.5-only syntax.
